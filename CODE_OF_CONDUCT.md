# Code of Conduct

## Our pledge

We pledge to make participation in Sidq welcoming and harassment-free for
everyone, regardless of identity, background, experience, or ability.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique ideas and evidence, not people.
- Accept correction and take responsibility for mistakes.
- Protect private data and credentials encountered while reproducing issues.
- Respect project boundaries, licences, and source attribution.

Harassment, threats, discriminatory language, unwanted sexual attention,
doxxing, and sustained disruption are not acceptable in project spaces.

## Enforcement

Report conduct concerns privately to the repository maintainers. Do not include
sensitive details in a public issue; if no private channel is listed, ask only
for one. Maintainers will
review reports promptly, protect reporter privacy where possible, and may edit,
remove, or reject contributions or temporarily or permanently restrict
participation. Good-faith reports will not be retaliated against.

This code applies in repository spaces and when someone is officially
representing the project.
