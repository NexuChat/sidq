SIDQ صدق

Catalog verification, before an agent acts

FILE 00 · INTAKE

Everyone is teaching agents to read the catalog.
Nobody is asking whether it is lying.

Sidq verifies schema, lineage, governance, ownership, and documented claims before an agent acts. It returns PASS, WARN, or BLOCK — and writes an evidence receipt back to DataHub that the next agent re-checks.

Runs a real command on the host and prints the real output. 5 proof runs per client every 10 minutes; a refusal says which limit applied and when it resets.

Agent B reads a receipt Agent A persisted in DataHub, then re-derives the answer itself. Read-only.

EXHIBIT C

      
The Receipt

      

        

          
PASS

          
Continue.

        

        

          
WARN

          
Review or escalate.

        

        

          
BLOCK

          
Stop — it was checked and refused. Never shown as unverified.

        

        

          
NOT VERIFIED

          
Missing, stale, or unreadable receipt. Check again.
