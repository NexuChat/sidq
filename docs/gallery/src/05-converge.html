03 / Shared trust — independent read

The writer does not certify itself.

An explicit audit can write the decision context to DataHub. A separate process then re-reads the current graph, policy hash, age, and recorded evidence before deciding whether that Receipt still holds.

Missing or stale context becomes NOT VERIFIED.
It never becomes a false PASS.
