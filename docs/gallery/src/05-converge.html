03 / The agents — memory

The audit that resumes.

The receipts one run writes are the memory the next run reads. Assets whose receipt still holds are vouched, the budget reaches assets no run has seen, and coverage converges under a budget that never changed.

The catalog is the ledger — any Sidq instance
resumes where any other stopped.

MAKE CONVERGE-DEMO — LIVE, OFFICIAL MCP ONLY 
$ make converge-demo
== run 1: spend the budget worst-first, write receipts ==
  examined          5
  findings          4
  NOT examined      45   (budget reached)
  receipts written  5 of 5

== run 2: same budget — the receipts vouch ==
  examined          5    ← different assets
  vouched           22   (a prior receipt still holds;
                         budget spent elsewhere)
  NOT examined      23   ← was 45
No state file, no sidecar, no daemon — receipts alone sidq audit --resume
